# Martech - Programação Básica

Este repositório reúne exercícios e exemplos desenvolvidos em **Python** durante os estudos de Programação Básica no curso Martech.

O material aborda conceitos fundamentais de lógica de programação, estruturas de dados simples, funções e resolução de problemas práticos.

## Conteúdos Abordados

- Entrada e saída de dados
- Estruturas de repetição
- Funções
- Modularização de código
- Listas
- Tuplas
- Dicionários
- Operações matemáticas
- Resolução de exercícios práticos

## Descrição das Pastas

### Dicionário

Contém exemplos e exercícios com dicionários em Python.

Principais temas:

- Criação de dicionários
- Acesso a chaves e valores
- Percurso com `keys`, `values` e `items`
- Filtragem de dados com condições

### Função

Reúne exercícios sobre criação e uso de funções.

Principais temas:

- Definição de funções
- Parâmetros e retorno
- Separação de responsabilidades no código
- Modularização com arquivo auxiliar
- Cálculo de delta e raízes de equação do 2º grau

### Laço de repetição

Contém exercícios com estruturas de repetição.

Principais temas:

- Repetição de comandos
- Contadores
- Acumuladores
- Processamento de múltiplas entradas

### Listas

Reúne atividades envolvendo listas e armazenamento de valores em sequência.

Principais temas:

- Criação e preenchimento de listas
- Percurso por índice
- Cálculo de médias
- Comparação de valores
- Análise de dados coletados por sensores

### ProvaFinal

Contém exercícios de revisão e avaliação final, integrando diferentes conceitos estudados.

Principais temas:

- Funções
- Listas
- Cálculos percentuais
- Simulação de resultados
- Organização de dados informados pelo usuário

### Tupla

Reúne exemplos e exercícios com tuplas.

Principais temas:

- Criação de tuplas
- Acesso a elementos
- Percurso de dados imutáveis
- Uso de estruturas simples para organização de informações

## Como Executar os Arquivos

Para executar os exercícios, é necessário ter o Python instalado.

No terminal, acesse a pasta do arquivo desejado e execute:

```bash
python nome_do_arquivo.py
```

Exemplo:

```bash
python Exercicio01.py
```

Alguns arquivos utilizam módulos auxiliares da mesma pasta. Nesses casos, execute o arquivo a partir da própria pasta onde ele está localizado.

## Observação

A pasta `__pycache__` é criada automaticamente pelo Python quando módulos são importados. Ela não precisa ser alterada manualmente.
